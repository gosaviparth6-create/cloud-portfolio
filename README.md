\# Cloud-Deployed Static Portfolio with CI/CD



Live Site URL: https://gosaviparth6-create.github.io/cloud-portfolio/



\## Syllabus Unit Mapping



\### Unit 1: Linux \& Virtualization

\- \*\*Local Environment:\*\* Practiced file operations, folder navigation, and directory structure management using PowerShell/CLI.

\- \*\*Git \& Authentication:\*\* Configured local Git CLI user credentials and environment setup.



\### Unit 2: Networking

\- \*\*Protocols \& Ports:\*\* The portfolio is served over HTTPS (Port 443) and standard HTTP (Port 80).

\- \*\*DNS Resolution:\*\* GitHub Pages automatically resolves requests through global CDN endpoints.



\### Unit 3: Cloud Fundamentals

\- \*\*Deployment Model:\*\* Deployed via Public Cloud (Serverless Static Hosting).

\- \*\*Service Model:\*\* Uses Platform as a Service (PaaS) / Static Site Hosting, abstracting underlying server hardware management.

\- \*\*Shared Responsibility Model:\*\* The cloud host maintains physical server infrastructure and network availability, while the developer manages site source code, routing settings, and repository security.



\### Unit 4: Core AWS / Cloud Concepts

\- \*\*Storage \& Hosting:\*\* Utilized static object store deployment concepts (equivalent to AWS S3 Static Website Hosting / Azure Blob Storage).

\- \*\*Identity \& Access Management (IAM):\*\* Managed access via GitHub repository permissions and user access keys.



\### Unit 5: DevOps, Git \& Monitoring

\- \*\*Version Control:\*\* Managed source code using Git (commits, branches, remote tracking).

\- \*\*CI/CD Pipeline:\*\* Configured automated deployment triggers on every `git push` to the `main` branch.

\- \*\*Cost Controls:\*\* Utilized zero-cost serverless hosting tier to ensure $0 spend limits.
